# Prince Kumar - Developer Portfolio

A highly interactive, deeply customized personal portfolio built with React and Vite. It features a modern dark-mode aesthetic with custom 3D animations, interactive typography, and synthwave-inspired UI elements.

## ✨ Key Features

- **Dynamic Interactive Typography:** The hero section features massive background text that reacts to user interactions, with individual characters jumping and lighting up in neon colors on hover/click.
- **Synthwave ATM Cards:** The "What I Do" section displays skills using premium, 3D animated "ATM cards" with fluid neon wireframe backgrounds, embossed monospace fonts, and EMV chip icons.
- **3D Parallax Grid:** A futuristic 3D perspective grid in the background that moves and reacts to mouse movements.
- **Responsive & Fluid Layout:** Fully responsive layout that elegantly scales down for mobile devices without losing the premium aesthetic.
- **Custom Aesthetic:** Beautiful dark glassmorphism (frosted glass) effects, pulsing neon badges, and meticulously crafted CSS animations.

## 🛠️ Tech Stack

- **Framework:** React.js + Vite
- **Styling:** Custom Vanilla CSS (with advanced CSS animations, transforms, and gradients)
- **Icons:** Lucide React

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Presktok/Presktok.github.io.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Presktok.github.io
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173` to view the site.

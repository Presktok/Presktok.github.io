# Presktok

Welcome to Presktok! This project is a modern web application built with React and Vite.

## Overview
Presktok provides an interactive user interface with dynamic features and a responsive design.

## Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
